# v2.0.2

## Dependencies

- Update `golang.org/x/net` from `v0.55.0` to `v0.63.0` for HTML parsing.
- The module path remains `github.com/soulteary/html-to-markdown/v2` and the minimum Go version remains 1.27.3.

## Validation

The dependency update passes module verification, build, vet, and the complete uncached race suite with Go 1.27.4 on Linux amd64. All 17 packages retain 100% statement coverage, including examples and internal helpers. Existing golden fixtures pass without updates.

The repository's benchmark material describes measurements of v2.0.1 against upstream v2.5.2. Those historical measurements and their dependency versions are retained for reproduction; they are not new performance claims for v2.0.2.

## Install

```sh
go get github.com/soulteary/html-to-markdown/v2@v2.0.2
```
